# コードも分からん医学生が、AIと作ったもの

ブラウザだけで動く2つのアプリ。ビルド不要・サーバー不要・登録不要。

| | 何をするもの |
|---|---|
| **[Focus Desk](./focus/)** | 音を鳴らさない学習タイマー。試験までの日数と「落としたときの重さ」で科目を並べる |
| **[TAVI MAPS](./tabi/)** | 旅行中に「で、結局いつ出ればいいのか」だけを出す旅のしおり |

どちらも iOS アプリとして先に作ったものを、Web へ移したものです。

## 作り

素の HTML / CSS / JavaScript だけ。npm も、ビルドも、バックエンドもありません。
GitHub Pages にそのまま置けます。

```
index.html        入口
assets/base.css   2つで共通の土台
focus/            Focus Desk
tabi/             TAVI MAPS
```

### 時間の持ち方（両方に共通）

**経過秒を数え上げていません。** 保存しているのは開始・休憩・終了の「時刻」だけで、
画面に出している時間はその引き算です。

だからタブを閉じても、翌日開いても、端末を再起動しても狂いません。
iOS 版と同じ作りで、Web でもそのまま成立しました。

### 外と通信するところ

- **天気**：[Open-Meteo](https://open-meteo.com/)（登録もキーも不要）
- **地名検索・地図**：[OpenStreetMap / Nominatim](https://nominatim.org/)

渡しているのは地点の緯度経度と、探す言葉だけです。旅程の中身は送っていません。
それ以外のデータは、すべてブラウザの `localStorage` に入ります。

### 「自動でついた場所」と「自分で決めた場所」を分けている

地名検索は普通に間違えます。同名の別施設が別の県に出る。
黙って入れると、**間違った座標で天気と所要時間が出て、しかも正しそうに見えます。**

そこで「採用するかどうか」ではなく「**出どころが見分けられるかどうか**」で守っています。
自動でついた場所には印がつくので、おかしいと思ったときに何を疑えばいいか分かります。

## 動かす

サーバーは要りません。`index.html` をブラウザで開くだけでも動きます。

ES モジュールを使っているので、ローカルで確認するときだけ簡易サーバーを挟んでください。

```
python3 -m http.server 8000
```

## 公開前の確認

個人情報が混ざっていないかを機械で確かめます。コミット前に実行してください。

```
./tools/check-privacy.sh
```

## まだできていないこと

- 端末をまたいだ同期（ブラウザの中にしか残りません）
- 通知（タブを閉じている間は鳴りません。そもそも無音の設計です）
- 経路の所要時間は直線距離からの概算です。道の形も渋滞も見ていません
